# 受け入れ基準（目標契約）: Find Ponta!

仕様の詳細は `DESIGN.md`。主観評価（面白さ・快適さ）はユーザーのプレイ確認の領分で、ここには含めない。

## 共通基準（機械検証）
- [ ] `npx tsc --noEmit` エラー0
- [ ] `npx vite build` 成功
- [ ] AIプレイテスト完走（レポートにエラーなし・Result到達）

## 共通基準（スクショ/コード検証）
- [ ] Pointer Events でマウス・タッチ両対応（コード根拠を引用）
- [ ] スマホビューポート（幅400px前後）で UI が崩れない（スクショ根拠）
- [ ] ローディング表示あり・黒画面で待たせない（スクショ根拠）
- [ ] 外部画像・音声・外部ドメインを参照していない（Grep 根拠）
- [ ] BGM/SFX の音量・消音が独立して操作でき、言語（en/ja）・音量がリロード後も復元される

## ゲーム固有基準（定量）
### 構成
- [ ] シーンが Preload / Title / StageSelect / Game / Result / Settings の6つあり、全遷移（Title→StageSelect→Game→Result→StageSelect/Next/Retry）が動く
- [ ] ステージ4つ。背景は bg_park / bg_market / bg_festival の3枚（S4 は bg_park の夜ティント再利用）
- [ ] ステージ N+1 は N クリア前はロック表示で選べない

### 配置（スクリプトで各ステージ100シードを検証）
- [ ] モブ数 S1=60 / S2=100 / S3=150 / S4=200、デコイ数 4 / 8 / 12 / 16、ボーナス数 0 / 0 / 1 / 2 と完全一致
- [ ] ポンタのエンティティ数が全ステージ・全シードで厳密に1
- [ ] 同一シードで再生成した全エンティティ（座標・種類・反転・スケール・ポーズ・動き）が完全一致
- [ ] ポンタ中心が世界中心から250px以上、世界端から80px以上
- [ ] デコイ-ポンタ最小距離 S1-2=300px / S3=150px / S4=100px。S3 は3体以上、S4 は4体以上が600px以内
- [ ] ポンタの可視面積が S1≥85% / S2≥80% / S3≥75% / S4≥70%
- [ ] デコイ種 S1=D,E / S2=A,B,D,E / S3-4=A〜E

### 動き（スクリプトで各ステージ100シードを検証）
- [ ] 全キャラ（ポンタ・デコイ・モブ）が正面/買い物/横向き歩き/追いかけっこのいずれかのポーズで描かれ、ポンタも他キャラと同じ割り当て規則に従う
- [ ] 往復キャラ・追いかけっこは歩行領域と世界端（80px）の内側だけを動く。追いかけっこは相方と対称（同じ振幅・周期・位相、反対側）
- [ ] 動いたときもポンタの可視面積が各ステージ下限−2%以上（独立した120時刻で検査）
- [ ] 当たり判定は表示中の位置に追従する。動くキャラの判定は静止キャラより半径10px広い
- [ ] クリア/失敗時は動きが止まり、ポンタは正面の絵に戻る
- [ ] **NORMAL はキャラが一切動かない**（位置・ポーズ固定、待機モーションなし）。**HARD のみ**動く。切り替えはステージ選択の NORMAL/HARD で、リロード後も保持される
- [ ] ベストは NORMAL/HARD 別に保存される。ステージ解放はどちらのクリアでも進む

### 操作
- [ ] 移動8px未満かつ500ms未満の入力のみタップ、8px以上でパン
- [ ] ズームは最小（背景を覆う倍率）〜3.0倍にクランプ。カメラは世界範囲内にクランプされ、390x844縦・1280x720横で背景外の余白が出ない
- [ ] ピンチ終了後150ms・連続タップ400ms以内の入力は無視
- [ ] ブラウザ標準のピンチズーム・ページスクロールが発生しない

### ルール・スコア
- [ ] ハズレ時間ペナルティ: 何もない場所 -2秒 / モブ -4秒 / デコイ -8秒（いずれもスコア-100）
- [ ] 制限時間 90 / 105 / 120 / 150秒。0秒で失敗し、1秒以内にポンタ位置へカメラ移動してリング表示
- [ ] ヒント上限 3 / 2 / 2 / 1。円半径は1回目450・2回目以降250、5秒表示、円中心はポンタ位置から半径の20%以上ずれる、使用ごとスコア-300
- [ ] ボーナス発見で+500点・+5秒。未発見でもクリア可
- [ ] タイマーはイントロ中・ポーズ中・タブ非表示中は停止。残り10秒以下は赤表示+timer_tick
- [ ] スコア = max(0, 1000 + 残り秒×20 + ボーナス×500 − ハズレ×100 − ヒント×300)（例: 残り50秒・ハズレ1・ヒント0 → 1900）
- [ ] スター判定が DESIGN.md どおり。ベストは固定シード/ランダムシード別に保存されリロード後も残る
- [ ] 結果画面にスター・スコア内訳・ハズレ数・ヒント数・取り逃しボーナス・シードを表示

### アセット

- [ ] 背景は1536x1024 JPG、スプライトは256x256（アイテム128x128）の透過PNG。四隅アルファ0、アルファ>0の画素にマゼンタ（R>200, G<80, B>200）が0
