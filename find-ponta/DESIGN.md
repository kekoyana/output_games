# Find Ponta!（ポンタをさがせ！）— 企画

- モード: 省力制作 / 全年齢 / テンプレ: `packages/phaser_template`（Phaser 3 + TS + Vite）/ 固定ポート 5306（workspace帯・台帳対象外）
- ジャンル: 隠れキャラ探し。迷子のたぬき「ポンタ」を、パン＆ズームできる街の中から1体だけ探す。
- 権利配慮: 赤白ストライプ・丸眼鏡・ニット帽、既存キャラを連想させる要素は背景・モブ・UIにも入れない。
- 構成: 背景 + 個別スプライトをゲーム側でシード付き乱数（mulberry32）で配置。ポンタはちょうど1体を配置後にassertで保証（違えば別シード、最大5回）。

## ポンタとデコイ
- ポンタ: 頭に緑の葉1枚 / 背中にオレンジ地に白水玉の風呂敷包み / 首に青マフラー。3点そろいが正解。
- デコイ: A=赤マフラー / B=包みなし / C=葉なし / D=黄色い葉+無地オレンジの包み / E=青地白水玉の包み+マフラーなし
- モブ14種: 猫(橙)・猫(黒)・うさぎ・きつね・くま・柴犬・ペンギン・ひよこ・男の子・女の子・おばあさん・コック・普通のたぬきA/B

## 操作
- Pointer Events統一。ドラッグ=パン（慣性0.92）/ ホイール・ピンチ=ズーム（最小=背景を覆う倍率〜3.0）/ タップ=判定。
- タップ判定: 移動8px未満かつ500ms未満。ピンチ終了後150ms無効、連続タップ400ms以内は無視。タップ半径は画面22px相当（世界座標で最大60px）。
- 正解判定: ポンタの当たり楕円（幅60%×高さ80%）。
- PC: WASD/矢印=パン, +/-=ズーム, H=ヒント, Esc=ポーズ。モバイル: 右下に +/-・ヒント・ポーズ（各48px以上）、`touch-action:none`。

## ルール
- ハズレ: 何もない場所 -2秒 / モブ -4秒 / デコイ -8秒。いずれもスコア-100。残り0で失敗（ポンタ位置へカメラ移動しリング表示）。
- ヒント: 1回目 半径450、2回目以降 半径250の世界座標円。中心はポンタ位置から半径の20%以上ずらす。5秒表示、スコア-300。
- ボーナス: 発見で+500点・+5秒。任意（未発見でもクリア可）。取り逃しは結果画面に表示。
- スコア = max(0, 1000 + 残り秒×20 + ボーナス数×500 − ハズレ×100 − ヒント×300)
- スター: 1=クリア / 2=ハズレ2以下かつヒント1以下 / 3=ハズレ1以下かつヒント0かつ残り40%以上
- 解放: ステージN+1はNクリアで解放。固定シード(S1=1101, S2=1202, S3=1303, S4=1404)と New Layout（ランダム）。ベストは別々に localStorage 保存。
- タイマーはイントロ・ポーズ・タブ非表示中は停止。残り10秒以下で赤表示+timer_tick。

## シーン
Preload → Title(Play/Settings/言語) → StageSelect → Game(手配書カードのイントロ→探索) → Result(スター・内訳・ハズレ・ヒント・取り逃し・シード・Next/Retry/New Layout) / Settings（テンプレ流用: BGM・SFX音量、言語、データ消去）

## 共通仕様の適用
- 対応言語: en / ja（テンプレ最小セット。NSFW 7言語標準は対象外）。UIラベルは英語固定可、手配書・イントロ・結果文言のみ日英。
- BGM: WebAudio合成ループ1曲（外部音声なし）、ON/OFFと音量。SFX 9種（ui_click, tap_miss, tap_wrong_mob, tap_wrong_decoy, hint, bonus_found, found_fanfare, timer_tick, fail）をWebAudio合成、独立した音量・消音。
- 設定・保存: Settingsから言語・音量、`setStorageNamespace("find-ponta")` で復元。
- 読み込み: Preloadでプログレスバー。外部URL参照なし。

## 動き（ポーズ）
- 全キャラ（ポンタ含む）に正面＋4ポーズ（side=横向き歩き / shop=買い物 / flee=逃げる / chase=追いかける）。素材は右向きで、左へ動くときは左右反転。
- 割り当て: 追いかけっこ（2体組・約14%）→ 横向き歩き（約24%）→ 買い物（約13%）→ 残りは正面。ポンタも同じ規則。
- 横向き歩き: 水平往復（振幅40〜90px・26〜40px/秒）。追いかけっこ: 近い2体が一緒に往復（振幅80〜130px・58〜82px/秒）。折り返しで逃げる側と追う側が入れ替わる（鬼ごっこ）。
- 位置は時刻だけで決まる（三角波）。描画と当たり判定は同じ関数。動いたときのポンタ/ボーナスの可視面積が下限を割る動きは配置時に取り消す。
- **難易度**: NORMAL=止まった絵（ポーズ・向きは配置時のまま固定、待機モーションもなし）/ HARD=上記の動きが有効。ステージ選択のトグルで切替（保存）。スコア計算は共通、ベストのみ別保存。動くキャラのタップ判定は半径+10px（HARD のみ）。
- 買い物・正面は小さな待機モーション（HARD のみ）（跳ねる/揺れる/深呼吸）。ボーナスは浮遊。
